Language reference

ND Script v1 — what you can write

Header (required, first line): //@version=1. A script without it does not run, and the error says so.

Declaration (required, exactly once, before any plot): indicator("Title", overlay=true). overlay=true draws on the price chart; overlay=false draws in a separate pane below it. The overlay flag may be omitted (defaults to true).

One statement per line. A statement never spans lines. Comments start with // and run to the end of the line.

Assignments: name = expression. Names start with a letter or underscore and may contain letters, digits and underscores. A name can be defined only once — there is no reassignment and no :=. Define a name before you use it.

Series you can read: open, high, low, close, volume, bar_index (0-based). na means "no value". For close-only symbols and the index, open/high/low are na where unpublished — never fabricated.

Operators: + - * / %, unary -, > < >= <= == !=, and or not (or && || !), parentheses, ternary cond ? a : b, and history expr[N] where N is a non-negative integer (0 = the current bar, 1 = the previous bar).

Built-ins (all series to series, single output):

  • sma(series, length) — mean of the last length bars; null before bar length−1.
  • ema(series, length) — k = 2/(length+1), seeded on the first value, null before bar length−1 by absolute bar index. A series that itself starts late becomes non-null at its first value once past bar length−1.
  • rsi(series, length) — Wilder's RSI: seeded from the first length consecutive valid changes, then Wilder smoothing; average loss 0 gives 100 (or 50 when average gain is also 0). A null change yields null for that bar; the Wilder state freezes across the gap.
  • macd(series, fast, slow) — fast EMA minus slow EMA. signal(macdSeries, length) is its EMA; the histogram is macd − signal in user arithmetic.
  • stdev(series, length) — population standard deviation of the last length bars; null before bar length−1 or if the window holds a null.
  • highest(series, length) / lowest(series, length) — rolling maximum / minimum including the current bar; null before bar length−1 or if the window holds a null.
  • crossover(a, b) — true when a was at or below b on the previous bar and above b now; crossunder(a, b) mirrors it. Both are false on the first bar and whenever any involved value is null.
  • abs(x), min(a, b), max(a, b) — element-wise; null propagates.

Length arguments must be constant positive integers on every bar — len = 20 then sma(close, len) works, but a length that varies bar to bar is a named error.

Null rules: a null input bar makes its output bar null, except and/or which use three-valued logic (false and na is false, true or na is true). Division or modulo by zero is null, never an error.

Outputs: plot(series, "Title", color) — title required, color optional (a fixed palette cycles when omitted), at most 8 plots, at least one plot required. hline(number, "Title", color) — the level must be a number literal, at most 8 lines; unlike Pine, hlines are allowed in either pane because this page has a single indicator pane. bgcolor(condition, color) — the condition must be true/false, at most 4 calls; flagged bars render as a translucent wash (the chart library has no per-bar background API, so the wash is a full-height translucent column, not a price-band fill).

Errors name the line and the problem. An unknown function lists the available built-ins. On any error the chart clears — a stale plot is never presented as the current result.

Deliberately not in v1, with reason: user-defined functions (keeps the engine auditable; variables plus built-ins cover indicator cases); strategy / backtest mode (the inventory scope is indicators; a backtest engine needs its own ledger and cost gates, a separate build); plotshape / plotchar / fill (a second chart layer; plots plus bgcolor plus hline cover indicator cases); alerts (no accounts, no notification channel); multi-timeframe or intraday bars (daily bars only — the published full-history archive); input.* controls (the editor is the input).

Method

How this page is built

Sources (all published, no new feed): scripts run on the site's published daily-bar files — full OHLC bars with volume and turnover for 418 symbols, close-only bars for 14 symbols whose full history is not published, and the NEPSE index series. The page reads published files only; it never calls a live source and never proxies one.

Execution: your script is parsed by a restricted recursive-descent parser and evaluated as arrays of numbers over the bars. Your text is never passed to eval or inserted as HTML. It never leaves your browser: the share link carries the script in the URL fragment, which is never sent to a server.

Rendering: full-history symbols draw candlesticks with a volume histogram; close-only symbols and the index draw a close line, because their open/high/low are not published — flat candles are never fabricated. The volume histogram is hidden whenever the series carries no volume. Bars are as-published closes, NOT bonus-adjusted: a bonus ex-date appears as a step in the series.

Freshness: the page re-checks the data manifest every 60 seconds. A newly published session shows a note; your current view is never yanked away — run again to include it.

Honesty bounds: indicators only, educational framing only. Nothing on this page is a buy, sell or hold call, and nothing is presented as a prediction. A script's output is only as good as the bars it ran on.

Not shown here, with reason: intraday bars — the published archive is daily; per-bar time — daily bars carry dates, not times; saved scripts — there are no user accounts on this site, so sharing is by link, not by account; turnover — present in the source history files but not a script series, because indicators operate on price and volume series (turnover is the volume×price aggregate, not an independent input).
