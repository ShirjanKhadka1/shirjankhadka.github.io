Method

How this page is built

Sources (all published, no new feed): the trade tape is the Chukul floorsheet bydate API (public), pulled server-side at data-collection time and published as 1000-trade chunk files per session. The page renders published files only — it never calls the source live. Broker names come from the site's broker directory; symbols link to their stock pages.

Order: trades stay in the source's own order, newest first, so page 1 is the session's latest trades. A filter loads the session's chunks once and filters locally; it never samples.

Coverage: full tape is retained for the last 5 trading sessions only. Sessions before the tape archive (which starts 26 Oct 2026 — 23 Oct 2026 was the Kojagrat Purnima holiday) and sessions pruned out of the window render honestly unavailable, never estimated. A session whose tape fetch is partial states its exact coverage in its manifest.

Closed sessions only: live-day rows carry no broker codes, so a live-day tape would have no buyer or seller to show. This page therefore covers closed sessions, after the tape is final.

Not shown here, with reason: per-trade time — the source publishes none; market depth / order book — the source publishes trades only, not orders; intraday provisional tape — live-day rows lack broker codes (see above).

Refresh: the session list re-checks every 60 seconds; a newly published session appears in the picker with a note, and the current view is never yanked away.
